# Minecraft PS3 Edition — Backups originales

Archives des backups originales de **Minecraft PlayStation 3 Edition**, utilisées par
[MC3 Toolkit](https://github.com/INF3CONxR7/MC3_Toolkit).

Quand on crée un projet dans MC3 Toolkit, l’application télécharge l’archive de la version choisie,
vérifie son empreinte SHA-256, puis la place dans le dossier « Original » du projet (copie de
référence, jamais modifiée) et dans « Workspace » (copie de travail).

## Archives

Les archives sont jointes aux [Releases](../../releases), une Release par version du jeu.
